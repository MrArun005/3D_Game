# Characters

Generated by `tools/characters.mjs`, not authored by hand. Do not edit the
`.glb` files here — edit the preset or the body model and regenerate.

```bash
npm run genchar              # rebuild the whole cast
npm run genchar -- hero      # rebuild one
npm run genchar -- --list    # print the parameter set
```

## How it works

`tools/lib/body.mjs` builds the body the same way `vehicle/` builds the car:
cross-sections lofted into a surface. There is no morph-target library — the
mesh is **rebuilt from the parameters**, which is why every slider is
continuous and why adding a parameter costs nothing at runtime.

`tools/lib/rig.mjs` places a 27-joint skeleton and computes skinning weights by
distance to bone *segments* (a joint-point test puts the whole forearm on the
elbow). Two influences per vertex.

## Mixamo

Joint names use the **Mixamo convention** (`mixamorig:Hips`, `mixamorig:LeftArm`
…) and the rest pose is a **T-pose**, both deliberately: a clip downloaded free
from Mixamo retargets onto this rig with no bone mapping. That is the intended
animation source — walk, run, idle, enter/exit vehicle.

## What this technique cannot do

- **Faces.** No eyes, nose or mouth, and no facial rig. A head is a lofted
  ovoid. Anything close-up needs an authored head.
- **Fingers.** Hands are flattened stubs.
- **Cloth simulation, hair strands, subsurface skin.**

For a hero character seen in cutscenes, author one in Blender — MPFB2 is the
free parametric option — and keep these for the crowd, which is where the
variety matters and the camera never gets close.
