# public/models/lib — downloaded characters

Rigged, textured, animated characters from the three.js examples repo. These are
working game characters, not blockouts.

| File | Tris | Joints | Textures | Clips |
| --- | --- | --- | --- | --- |
| `Soldier.glb` | 11,376 | 49 | 2 | Idle, Run, Walk, TPose |
| `Michelle.glb` | 28,106 | 65 | 4 | SambaDance, TPose |
| `Xbot.glb` | 49,112 | 67 | 0 | agree, headShake, idle, run, sad_pose, sneak_pose, walk |
| `RobotExpressive.glb` | 3,237 | 43 | 0 | Dance, Death, Idle, Jump, No, Punch, Running, Sitting, Standing, ThumbsUp, Walking, WalkJump, Wave, Yes |

**Soldier is the one to build on** — textured, sensibly sized for a game
character, and it ships with the three clips the game actually needs.

## Licence — read before shipping

Soldier, Michelle and Xbot are **Mixamo-derived**, bundled in the three.js repo
for its examples. Fine for prototyping. Before shipping, download equivalents
from mixamo.com under your own free Adobe account so the licence is yours.
RobotExpressive is by Tomas Laulhe, modified by Don McCurdy — check the
per-model notes in the three.js repo for exact terms.
